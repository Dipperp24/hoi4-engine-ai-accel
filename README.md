# hoi4-rust-accel (`v1.1` — Linux & Windows)

Нативный ускоритель движка Clausewitz и нечитерный усилитель ИИ для **Hearts of Iron IV** (`Operation Postern v1.20.0.0.8873`, 64-бит) в двух синхронизированных сборках:
- **Linux (`LD_PRELOAD`, нативный Rust):** `libhoi4_rust_accel.so` + лаунчер `launch_hoi4.sh`
- **Windows (`version.dll` прокси, C++20 MSVC x64 ABI):** `windows/dist/version.dll` (подробная инструкция: `windows/README_WINDOWS.md`)
- **Единый конфиг для обеих ОС:** `hoi4_accel.ini` (либо переменные окружения `HOI4_ACCEL_*`).

### Ключевые гарантии
- **100% неинвазивно:** оригинальные бинарники игры (`hoi4` и `hoi4.exe`) и игровые файлы на диске не изменяются ни на один байт.
- **Без читов и нарушения баланса:** ускоритель не трогает `NMilitary` / `NProduction` / `NCountry` (правила боя и производства одинаковы для игрока и бота) и не рисует боту бесплатные заводы или снаряжение. Все улучшения ИИ работают строго через весовые коэффициенты принятия решений `NDefines::NAI` / `NAITheatre` и точечный перехват очереди строительства.
- **Нулевые конфликты с модами:** работает прямо из `.so` / `version.dll` с ваниллой, всеми DLC, сохранениями и модами (*Road to 56, Kaiserreich/KaiserreduX, BlackICE, TNO, Millennium Dawn, The Fire Rises* и др.).
- **Версионность и быстрый откат:** в GitHub Releases доступны готовые сборки обеих версий (`v1.0.0` — чистая оптимизация движка и снабжения; `v1.1.0` — + умное расширение авиабаз и тактический ИИ на базе Sheep AI / Discord AI), а любой модуль можно мгновенно отключить флагом `= 0` в `hoi4_accel.ini`.

---

## Быстрый запуск

### Windows
Скопируйте `version.dll` и `hoi4_accel.ini` из `windows/dist/` (или из архива релиза `hoi4-accel-v1.1.0-windows-x64.zip`) прямо в папку с `hoi4.exe` и запускайте игру как обычно. Подробнее — в `windows/README_WINDOWS.md`.

### Linux (Steam)
В Steam: **ПКМ по Hearts of Iron IV → Свойства → Параметры запуска**:
```bash
/путь/к/hoi4-rust-accel/launch_hoi4.sh %command%
```
Все настройки и пресеты (`smooth`, `balanced`, `turbo`, `pure`, `none`, а также включение/отключение отдельных модулей ИИ и движка) меняются прямо в `hoi4_accel.ini`.

## Что входит в `v1.1` (19 модулей движка и ИИ)

### Новое в `v1.1` — умные авиабазы и рассудительный тактический ИИ (на базе Sheep AI / Discord AI)
1. **`AiSmartAirbase` (`ai_smart_airbase = 1`, `CAIConstruction::GetBuildingQueuePrio` + `NDefines::NAI`)** — исправляет корневой баг очереди строительства Paradox, из-за которого запланированные ботом расширения авиабаз (`air_base`) получали приоритет `CONSTRUCTION_PRIO_UNSPECIFIED = 0.50` и годами висели с `0` фабрик позади военных (`0.70`) и гражданских (`0.80`) заводов:
   - точечный перехват `GetBuildingQueuePrio` проверяет флаг `CBuilding::m_bIsAirBase` и повышает приоритет **только уже запрошенных ИИ авиабаз** в `3.2x` (`0.50 → 1.60`), не трогая бункеры, ПВО, радары и топливные баки (остаются `0.50`) и сохраняя безусловный приоритет экстренных узлов снабжения (`4.50`) и железных дорог (`8.00`);
   - бот перебазирует авиакрылья ближе к линии фронта уже при падении покрытия миссии ниже **75%** (вместо 50%), активнее прикрывает наземные сражения и защищает узлы снабжения от ударов по логистике.
2. **`AiTacticalPrudence` (`ai_tactical_prudence = 1`, 33 нечитерных параметра `NDefines::NAI` по мотивам Sheep AI / Discord AI)**:
   - **Конец бессмысленному суициду об окопы:** повышен минимальный порог прочности дивизий для наступления по плану (`30% → 50%` на агрессивном и `60% → 75%` на осторожном плане), а заведомо проигрышные атаки сворачиваются через **20 часов** при перевесе обороны `1.25x` (вместо 48 часов битья головой в стену при `1.50x`);
   - **Ударные танковые кулаки (`AIFC` — AI Force Concentration):** ИИ концентрирует бронетехнику, механизированные и опытные ударные части (`hardness 300→800`, `armor 30→80`, `soft/hard attack x2`) в сфокусированные прорывные кулаки, ждёт набора **42% организации** перед ударом (вместо 20% в ванилле!), нацеливает прорывы на **вражеские узлы снабжения и порты** и обходит горы (`path cost 3.0 → 4.0`);
   - **Дисциплина местности и сохранение окопанности:** жёсткий запрет загонять танки в горы (`-15.0`) и джунгли (`-20.0`), удвоенный вес окопанности (`2.0 → 4.0`, пехота перестаёт бесконечно бегать вдоль фронта и терять бонус лопат), учёт превосходства в воздухе (`x2`) и нехватки снабжения (`x1.5`) при оценке сил на фронте;
   - **Ежедневный поиск слабых точек и защита от котлов:** пересчёт выступов фронта и угроз окружения каждые **24 часа** (вместо 72 часов в ванилле), подрезание вражеских выступов (`bulge cutoff 1.20..1.80`) и точечные микро-атаки по слабым клеткам (`max_micro_attacks 3 → 5`), чтобы бот не стоял вечно в ступоре, но и не лез сам в «мешки».

### Глубокие оптимизации движка, памяти, гражданских войн и логистики (`v1.0` → `v1.1`)
3. **`AiSmartSupply` (`ai_smart_supply = 1`)** — проверка узких мест снабжения каждые **24 ч** (вместо 168 ч), упреждающий апгрейд ЖД при **65%** загрузки узла, ранняя моторизация хабов грузовиками (`95%` вместо `80%`, проверка раз в `24 ч`), приоритет стройки **узлов снабжения (`4.50`)** и **ЖД (`8.00`)**, глубина поиска `5 → 9`.
4. **`FastAlloc` (`fast_alloc = 1`)** — lock-free slab-арена на `128 МБ` + `TLS`-кэш потоков для `CPdxNewDeleteAllocator` (`<= 512 Б`).
5. **`FastModifier` (`fast_mod = 1`)** — безветвевой бинарный поиск `CModifier::GetValue` на инструкциях `CMOV`.
6. **`CivilWarFix` (`civil_war_fix = 1`)** — устраняет многосекундный фриз при начале гражданских войн (коалесценция 100+ пересборок оверлея карты/побережий в 1).
7. **`AiThrottleMinors` (`ai_throttle_minors = 1`)** — разгрузка почасового `CCountryAI` спящих мирных миноров (`< 12` областей, вне войны, не мажор, не игрок) с сохранением суточных таймеров.
8. **`CountryGrain` (`country_grain = 1`)** — `chunk_size = 1` для параллельных циклов масштаба стран (`17..=220`).
9. **`FastSched` / `FastWait` / `FastYield` / `FastEvent` / `NoJobClock` / `Affinity`** — полная переработка планировщика потоков Clausewitz без холостого `sched_yield` / `SwitchToThread` шторма.
10. **`SmoothFPS` + `TargetFPS`** — анти-фриз рендер 30 FPS (60 FPS при движении камеры) и адаптивный мульти-тик на 5-й скорости.
11. **`QuietLog` / `FastSave` / `NoTelemetry`** — дедупликатор спама `error.log`, сохранение без блокирующего `fsync`/`FlushFileBuffers` и чистое отключение телеметрии SDK.

## Конфигурация (`hoi4_accel.ini` и переменные окружения)

| Ключ в `hoi4_accel.ini` | Переменная окружения | По умолчанию | Описание |
| :--- | :--- | :---: | :--- |
| `preset` | `HOI4_ACCEL_PRESET` | `smooth` | `smooth` / `balanced` / `turbo` / `pure` / `none` |
| `ai_smart_supply` | `HOI4_ACCEL_AI_SMART_SUPPLY` | `1` | Умная постройка ЖД, узлов снабжения и моторизация хабов |
| `ai_smart_airbase` | `HOI4_ACCEL_AI_SMART_AIRBASE` | `1` | Умное расширение фронтовых авиабаз (`air_base` prio `3.2x`) и покрытие миссий |
| `ai_tactical_prudence` | `HOI4_ACCEL_AI_TACTICAL_PRUDENCE` | `1` | Рассудительная тактика, прощупывание слабых мест и танковые кулаки `AIFC` |
| `ai_throttle_minors` | `HOI4_ACCEL_AI_THROTTLE_MINORS` | `1` | Разгрузка почасового ИИ спящих мирных миноров (`<12` обл.) |
| `fast_alloc` | `HOI4_ACCEL_FAST_ALLOC` | `1` | Lock-free slab + TLS аллокатор (`128 МБ`) для `<= 512 Б` |
| `fast_mod` | `HOI4_ACCEL_FAST_MOD` | `1` | Безветвевой `CMOV` бинарный поиск `CModifier::GetValue` |
| `country_grain` | `HOI4_ACCEL_COUNTRY_GRAIN` | `1` | `chunk=1` для параллельных циклов стран (`17..=220`) |
| `civil_war_fix` | `HOI4_ACCEL_CIVIL_WAR_FIX` | `1` | Устранение фриза при начале гражданских войн |
| `fast_sched` | `HOI4_ACCEL_FAST_SCHED` | `1` | Lock-free планировщик воркеров `PopTaskOrWait` |
| `fast_wait` | `HOI4_ACCEL_FAST_WAIT` | `1` | Lock-free `CTask::Wait` |
| `fast_yield` | `HOI4_ACCEL_FAST_YIELD` | `1` | Перехват циклов `sched_yield` / `SwitchToThread` |
| `fast_event` | `HOI4_ACCEL_FAST_EVENT` | `1` | Прямой `SYS_futex` пула потоков *(только Linux)* |
| `no_job_clock` | `HOI4_ACCEL_NO_JOB_CLOCK` | `1` | Вырезка системных часов на микрозадачах `ExecuteTask` |
| `affinity` | `HOI4_ACCEL_AFFINITY` | `1` | Привязка потоков к физическим ядрам и SMT |
| `quiet_log` | `HOI4_ACCEL_QUIET_LOG` | `1` | Дедупликатор спама `error.log` |
| `fast_save` | `HOI4_ACCEL_FAST_SAVE` | `1` | Асинхронная запись сохранений без фриза диска |
| `no_telemetry` | `HOI4_ACCEL_NO_TELEMETRY` | `1` | Отключение телеметрии Paradox SDK |
| `target_fps` | `HOI4_ACCEL_TARGET_FPS` | от пресета | Целевой FPS при мульти-тике на 5-й скорости (`0` = выкл.) |
| `smooth_fps` | `HOI4_ACCEL_SMOOTH_FPS` | от пресета | Целевой FPS анти-фриза внутри тяжёлых тиков |
| `profile` | `HOI4_ACCEL_PROFILE` | `0` | Запись итогового отчёта по зонам и счётчикам при выходе |

## Откат между версиями (`v1.1.0` ↔ `v1.0.0`)

- **Через GitHub Releases (проще всего):** скачайте архив нужного релиза (`v1.1.0` или `v1.0.0`) со вкладки **Releases** репозитория и замените `version.dll` (Windows) или `libhoi4_rust_accel.so` (Linux).
- **Точечно без смены версии:** если в `v1.1.0` вы хотите вернуть ванильное поведение тактики или авиабаз, просто раскомментируйте в `hoi4_accel.ini` `ai_tactical_prudence = 0` и/или `ai_smart_airbase = 0`.
- **Через Git:** `git checkout v1.0.0` (или `git checkout v1.1.0`) и пересоберите командами ниже.

## Пересборка обеих версий из исходников

```bash
# Linux (target/release/libhoi4_rust_accel.so)
RUSTFLAGS="-C target-cpu=native" cargo build --release

# Windows (windows/dist/version.dll + windows/dist/hoi4_accel.ini)
bash ./windows/build_win64.sh
```
