# HoI4 Native Engine & AI Accelerator — Версия для Windows (`v1.4-win64`)

Нативный ускоритель движка и нечитерный оптимизатор ИИ для **Hearts of Iron IV (`hoi4.exe`, Operation Postern v1.20.0.0.8873, 64-бит)** под **Windows 10 / 11 (x86_64)**, а также для запуска Windows-версии `hoi4.exe` через **Proton / Wine**.

Работает как **прозрачный прокси `version.dll`**:
- **Ни один файл игры на диске не изменяется** (`hoi4.exe` остаётся на 100% оригинальным).
- **Не требует параметров запуска в Steam** — Windows автоматически подгружает `version.dll` из папки с `hoi4.exe`, перенаправляя системные вызовы в `C:\Windows\System32\version.dll`.
- **Без читов и нарушения баланса:** не меняет боевые статы игрока/бота (`NMilitary`), не даёт ИИ бесплатных фабрик/танков/дивизий и полностью совместим с модами (*Road to 56, Kaiserreich/KaiserreduX, BlackICE, TNO, Millennium Dawn, The Fire Rises* и др.).
- **Безопасность для лаунчера и обновлений:** DLL проверяет имя процесса (`hoi4.exe`), машинные сигнатуры прологов и патчей (`24/24`) и адреса виртуальных таблиц (`6/6`) перед установкой хуков. Дочерние процессы (`dowser.exe`, `crashreporter.exe`) пропускаются без изменений.

---

## Быстрая установка на Windows

Скопируйте два файла из папки `windows/dist/` (или из архива `hoi4-accel-v1.4.0-windows-x64.zip` в GitHub Releases):
1. `version.dll`
2. `hoi4_accel.ini`

прямо в корневую папку установленной игры рядом с `hoi4.exe` (обычно `...\Steam\steamapps\common\Hearts of Iron IV\`).

Запускайте игру как обычно. После старта рядом с `hoi4.exe` появится лог инициализации **`hoi4_accel.log`**, подтверждающий подключение всех модулей `v1.4-win64`.

> **Для мультиплеера:** выставьте `preset = pure` и одинаковые флаги `ai_*` у всех игроков в `hoi4_accel.ini`, чтобы избежать рассинхронов (OOS).

## Что оптимизировано в `hoi4.exe` (`v1.4-win64`, MSVC x64)

### Новое в `v1.4` — Нативный захват пустых клеток, доводка `supply_node`, анти-перетасовка фронтов и умный флот/десанты

| Модуль | RVA / VTable в `hoi4.exe` | Что делает |
| :--- | :--- | :--- |
| **`AiCaptureEmpty`** | `0x13fa480` (`CMoveCommand`) + `0x0ef2850` (`HasLandUnits`) + `0x0749580` (`IsAtWarWith`) + `0x02b6700` (`CSession::Post`) | Отправляет простаивающие дивизии ИИ (`>= 35%` орги, вне боя) в соседние **пустые вражеские клетки** через нативный MP-безопасный `CMoveCommand` (до 6 захватов/день) с **защитой от котлов** (`>= 2` своих дивизий в клетке либо 0 занятых врагом соседей). Лечит затуп в гражданках, Сибири и Африке |
| **`AiSmartSupply v3`** | `0x13a9fc0` (`FixSupplyBottlenecks`) + `0x11d0110` (`CAddConstructionCommand`) | Доведённый автостроитель сухопутных `supply_node`: **2-шаговый BFS** (работает и в Европе), порог `>= 12` заводов, `< 65%` снабжения у `>= 2` дивизий (или `< 35%` у `>= 1`), кулдаун 21 день, макс. 1 узел в очереди |
| **`AiTacticalPrudence v4`** | `0x1573929, 0x1573933` + `.data` `0x33e76b8..0x33ec038` (`43` параметра) | Добавлена **анти-перетасовка фронтов** (`REASSIGN_TO_ANOTHER_FRONT 0.50→0.20`, `IF_IN_COMBAT 0.20→0.05`, `REDEPLOY_DISTANCE_VS_ORDER_SIZE 1.0→2.0`) к сбережению снаряжения, `AIFC` и патчу пустых клеток |
| **`AiSmartNaval`** | `.data` `0x33e5a24..0x33eb518` (`15` параметров `NDefines::NAI`) | Останавливает суицидальные высадки 1–2 див. без порта (`NO_PORT_FACTOR 0.30→0.05`, готовность `25%→60%`, отмена проигрышного десанта за 5д вместо 30д) и концентрирует ударный флот (`NAVY_PREFERED_MAX_SIZE 25→60`, `MAX_PATROL_TO_STRIKE_FORCE 4.0→2.0`) |

## Настройка и откат версий

- Откройте `hoi4_accel.ini` любым текстовым редактором: любой модуль (`ai_capture_empty`, `ai_smart_naval`, `ai_smart_armor`, `ai_smart_supply`, `ai_tactical_prudence`, `ai_smart_peace`, `ai_smart_airbase`, `fast_alloc` и др.) можно отключить индивидуально, убрав `;` и поставив `= 0`.
- Для полного отката на `v1.3.0`, `v1.2.0`, `v1.1.0` или `v1.0.0` скачайте нужный архив из раздела **Releases** на GitHub и замените `version.dll` рядом с `hoi4.exe`.
- Для полного удаления просто удалите `version.dll` и `hoi4_accel.ini` из папки с `hoi4.exe`.
