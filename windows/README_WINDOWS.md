# HoI4 Native Engine & AI Accelerator — Версия для Windows (`v1.1-win64`)

Нативный ускоритель движка и нечитерный оптимизатор ИИ для **Hearts of Iron IV (`hoi4.exe`, Operation Postern v1.20.0.0.8873, 64-бит)** под **Windows 10 / 11 (x86_64)**, а также для запуска Windows-версии `hoi4.exe` через **Proton / Wine**.

Работает как **прозрачный прокси `version.dll`**:
- **Ни один файл игры на диске не изменяется** (`hoi4.exe` остаётся на 100% оригинальным).
- **Не требует параметров запуска в Steam** — Windows автоматически подгружает `version.dll` из папки с `hoi4.exe`, перенаправляя системные вызовы в `C:\Windows\System32\version.dll`.
- **Без читов и нарушения баланса:** не меняет боевые статы игрока/бота (`NMilitary`), не даёт ИИ бесплатных фабрик или дивизий и полностью совместим с модами (*Road to 56, Kaiserreich/KaiserreduX, BlackICE, TNO, Millennium Dawn, The Fire Rises* и др.).
- **Безопасность для лаунчера и обновлений:** DLL проверяет имя процесса (`hoi4.exe`), машинные сигнатуры прологов (`20/20`) и адреса виртуальных таблиц (`5/5`) перед установкой хуков. Дочерние процессы (`dowser.exe`, `crashreporter.exe`) пропускаются без изменений.

## Быстрая установка на Windows

Скопируйте два файла из папки `windows/dist/` (или из архива `hoi4-accel-v1.1.0-windows-x64.zip` в GitHub Releases):
1. `version.dll`
2. `hoi4_accel.ini`

прямо в корневую папку установленной игры рядом с `hoi4.exe` (обычно `...\Steam\steamapps\common\Hearts of Iron IV\`).

Запускайте игру как обычно. После старта рядом с `hoi4.exe` появится лог инициализации **`hoi4_accel.log`**, подтверждающий подключение всех модулей `v1.1-win64`.

> **Примечание для Linux + Proton:** если вы запускаете Windows-версию игры в Steam через Proton, укажите в параметрах запуска Steam:
> `WINEDLLOVERRIDES="version=n,b" %command%`
> (на самой Windows этого делать **не нужно**).

## Что оптимизировано в `hoi4.exe` (`v1.1-win64`, MSVC x64)

### Новое в `v1.1` — Умное расширение авиабаз и тактический ИИ (на базе Sheep AI / Discord AI)

| Модуль | RVA в `hoi4.exe` | Что делает |
| :--- | :--- | :--- |
| **`AiSmartAirbase`** | `0x1395220` (`CAIConstruction::GetBuildingQueuePrio`) + `0x33e6488..0x33eb380` | Исправляет приоритет очереди строительства для `air_base` (`CBuilding+0x363`): в ванилле авиабазы падали в `UNSPECIFIED = 0.50` и простаивали с 0 фабрик позади военных (`0.70`) и гражданских (`0.80`) заводов. Поднимает приоритет нужных фронтовых авиабаз в `3.2x` (`0.50 → 1.60`) без влияния на бункеры/ПВО/силосы и учит ИИ перебазировать крылья при покрытии миссий `< 75%` |
| **`AiTacticalPrudence`** | `.data` `0x33e7fe4..0x33ec038` (`33` параметра `NDefines::NAI`) | Нечитерное тактическое ядро по образцу *Sheep AI / Discord AI*: запрет самоубийственных атак полуживыми дивизиями (`min_str 0.30→0.50 / 0.60→0.75`), ранняя отмена провальных штурмов (`20 ч` вместо `48 ч`), сбор танковых/мех. ударных кулаков **`AIFC`** с ожиданием `42%` орг. и ударами по узлам снабжения/портам в обход гор, запрет танков в горах/джунглях (`-15 / -20`), сохранение окопанности пехоты (`x2`) и ежедневный расчёт котлов/выступов (`24 ч` вместо `72 ч`) |

### Модули памяти, потоков, гражданских войн и логистики (`v1.0` → `v1.1`)

| Модуль | RVA / VTable / IAT в `hoi4.exe` | Что делает |
| :--- | :--- | :--- |
| **`AiSmartSupply`** | `.data` `0x33e6124..0x33e9c48` (`NDefines::NAI`) | Проверка узких мест снабжения каждые **24 ч** (вместо 168 ч), апгрейд ЖД при **65%** насыщения узла, ранняя моторизация хабов грузовиками (`95%` вместо `80%`), приоритет стройки **узлов снабжения (`4.50`)** и **ЖД (`8.00`)**, глубина поиска `5 → 9` |
| **`FastAlloc`** | VTable `0x2798570` (`CPdxNewDeleteAllocator`) | Lock-free slab-аллокатор на `128 МБ` + Win32 `TlsGetValue` кэш потоков без блокировок `RtlAllocateHeap`/`RtlFreeHeap` для объектов `<= 512 Б` |
| **`FastModifier`** | `0x05a63d0` (`CModifier::GetValue`) | Безветвевой бинарный поиск на инструкциях `cmovbe` со скрытым возвратом `CFixedPoint` (`%rdx` → `%rax`) |
| **`CountryGrain`** | `0x2576ac0` (`CPdxParallelForRange::Init`) | `chunk_size = 1` для параллельных циклов масштаба стран (`17..=220`) |
| **`CivilWarFix`** | `0x1169250` (`CCivilWarSetup::Execute`) + VTable `0x29ea628+0x238` | Устраняет многосекундный фриз при старте гражданских войн (коалесценция 100+ пересборок карты/побережий в 1) |
| **`AiThrottleMinors`** | VTable `0x27b8c20` (`CCountryAI` `+0x10`, `+0x18`) | Разгружает почасовой ИИ спящих мирных миноров (`< 12` областей, вне войны, не мажор, не игрок) с сохранением суточных таймеров |
| **`FastSched` / `FastWait` / `FastYield` / `NoJobClock` / `Affinity`** | `0x255d2a0`, `0x255afb0`, IAT `0x27892c0`, `0x255d0f3`, `0x255a110` | Lock-free планировщик пула потоков без холостых вызовов ядра + привязка потоков к физическим ядрам |
| **`SmoothFPS` + `TargetFPS`** | `0x02bacd0`, `0x2297b50` + `0x0f88c10` | ~5 нс `RDTSC` анти-фриз рендер 30 FPS (60 FPS при движении камеры) + адаптивный мульти-тик на 5-й скорости |
| **`QuietLog` / `FastSave` / `NoTelemetry`** | `0x2550050`, `0x259d9e0`, IAT `0x2789a90` | Дедупликатор спама `error.log`, сохранение без блокирующего `FlushFileBuffers()` и чистое отключение телеметрии SDK |

## Настройка и откат версий

- Откройте `hoi4_accel.ini` любым текстовым редактором: любой модуль (`ai_smart_airbase`, `ai_tactical_prudence`, `ai_smart_supply`, `fast_alloc` и др.) можно отключить индивидуально, убрав `;` и поставив `= 0`.
- Для полного отката на `v1.0.0` скачайте архив `hoi4-accel-v1.0.0-windows-x64.zip` из раздела **Releases** на GitHub и замените `version.dll` рядом с `hoi4.exe`.
- Для полного удаления просто удалите `version.dll` и `hoi4_accel.ini` из папки с `hoi4.exe`.
