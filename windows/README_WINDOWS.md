# HoI4 Native Engine & AI Accelerator — Версия для Windows (`v1.2-win64`)

Нативный ускоритель движка и нечитерный оптимизатор ИИ для **Hearts of Iron IV (`hoi4.exe`, Operation Postern v1.20.0.0.8873, 64-бит)** под **Windows 10 / 11 (x86_64)**, а также для запуска Windows-версии `hoi4.exe` через **Proton / Wine**.

Работает как **прозрачный прокси `version.dll`**:
- **Ни один файл игры на диске не изменяется** (`hoi4.exe` остаётся на 100% оригинальным).
- **Не требует параметров запуска в Steam** — Windows автоматически подгружает `version.dll` из папки с `hoi4.exe`, перенаправляя системные вызовы в `C:\Windows\System32\version.dll`.
- **Без читов и нарушения баланса:** не меняет боевые статы игрока/бота (`NMilitary`), не даёт ИИ бесплатных фабрик или дивизий и полностью совместим с модами (*Road to 56, Kaiserreich/KaiserreduX, BlackICE, TNO, Millennium Dawn, The Fire Rises* и др.).
- **Безопасность для лаунчера и обновлений:** DLL проверяет имя процесса (`hoi4.exe`), машинные сигнатуры прологов (`22/22`) и адреса виртуальных таблиц (`5/5`) перед установкой хуков. Дочерние процессы (`dowser.exe`, `crashreporter.exe`) пропускаются без изменений.

## Быстрая установка на Windows

Скопируйте два файла из папки `windows/dist/` (или из архива `hoi4-accel-v1.2.0-windows-x64.zip` в GitHub Releases):
1. `version.dll`
2. `hoi4_accel.ini`

прямо в корневую папку установленной игры рядом с `hoi4.exe` (обычно `...\Steam\steamapps\common\Hearts of Iron IV\`).

Запускайте игру как обычно. После старта рядом с `hoi4.exe` появится лог инициализации **`hoi4_accel.log`**, подтверждающий подключение всех модулей `v1.2-win64`.

> **Для мультиплеера:** выставьте `preset = pure` и одинаковые флаги `ai_*` у всех игроков в `hoi4_accel.ini`, чтобы избежать рассинхронов (OOS).

## Что оптимизировано в `hoi4.exe` (`v1.2-win64`, MSVC x64)

### Новое в `v1.2` — Анти-бордергор мирных конференций, фикс пустых клеток, сбережение снаряжения и `QuietLog v2`

| Модуль | RVA в `hoi4.exe` | Что делает |
| :--- | :--- | :--- |
| **`AiSmartPeace`** | `0x1a8ca20` (`CalcStateActionScore`) + `0x0ebc270` (`IsStateClaimedBy`) + `0x33e652c..0x33e6698` | ИИ на мирной конференции даёт **`3x..5x`** областям, смежным со своей территорией или уже заявленными областями (и `2.5x` марионеткам рядом с сюзереном), режет сухопутные анклавы на **`-95%`** и разрозненные прибрежные на **`-75%`** (чтобы расширять один плацдарм, а не раскидывать «кляксы»). Свои корки (`IsCoreOf`) никогда не штрафуются |
| **`AiTacticalPrudence v2`** | `.data` `0x33e76b8..0x33ec038` (`40` параметров `NDefines::NAI`) | **Исправлен затуп перед пустыми клетками** (не трогает `PLAN_ATTACK_MIN_STRENGTH`, `LOCATION_BALANCE_TO_ADVANCE = 0.00`, мягкий `ENTRENCHMENT_WEIGHT = 2.2`) + **сбережение снаряжения от дефицита**: стоп суицида об укреплённые позиции (`0.50→0.95`), отмена проигрышных боёв за `12 ч` (`1.15x`), пауза спама новых дивизий пока армия в поле `< 88%`, стоп учений при `< 75%` снаряжения и танковые кулаки **`AIFC`** |
| **`QuietLog v2`** | `0x2550050` (`SetLogger`) | Дедупликация `error.log` без учёта номера строки `line` (`8192` слотов) — полностью блокирует 100-мегабайтный спам русской локализации (`RU_loc.txt`) |

| **`AiThrottleMinors`** | VTable `0x27b8c20` (`CCountryAI` `+0x10`, `+0x18`) | Разгружает почасовой ИИ спящих мирных миноров (`< 12` областей, вне войны, не мажор, не игрок) |

## Настройка и откат версий

- Откройте `hoi4_accel.ini` любым текстовым редактором: любой модуль (`ai_smart_peace`, `ai_tactical_prudence`, `ai_smart_airbase`, `ai_smart_supply`, `fast_alloc` и др.) можно отключить индивидуально, убрав `;` и поставив `= 0`.
- Для полного отката на `v1.1.0` или `v1.0.0` скачайте нужный архив из раздела **Releases** на GitHub и замените `version.dll` рядом с `hoi4.exe`.
- Для полного удаления просто удалите `version.dll` и `hoi4_accel.ini` из папки с `hoi4.exe`.
