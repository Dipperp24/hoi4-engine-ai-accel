# HoI4 Native Engine & AI Accelerator — Версия для Windows (`v1.3-win64`)

Нативный ускоритель движка и нечитерный оптимизатор ИИ для **Hearts of Iron IV (`hoi4.exe`, Operation Postern v1.20.0.0.8873, 64-бит)** под **Windows 10 / 11 (x86_64)**, а также для запуска Windows-версии `hoi4.exe` через **Proton / Wine**.

Работает как **прозрачный прокси `version.dll`**:
- **Ни один файл игры на диске не изменяется** (`hoi4.exe` остаётся на 100% оригинальным).
- **Не требует параметров запуска в Steam** — Windows автоматически подгружает `version.dll` из папки с `hoi4.exe`, перенаправляя системные вызовы в `C:\Windows\System32\version.dll`.
- **Без читов и нарушения баланса:** не меняет боевые статы игрока/бота (`NMilitary`), не даёт ИИ бесплатных фабрик/танков/дивизий и полностью совместим с модами (*Road to 56, Kaiserreich/KaiserreduX, BlackICE, TNO, Millennium Dawn, The Fire Rises* и др.).
- **Безопасность для лаунчера и обновлений:** DLL проверяет имя процесса (`hoi4.exe`), машинные сигнатуры прологов и патчей (`24/24`) и адреса виртуальных таблиц (`6/6`) перед установкой хуков. Дочерние процессы (`dowser.exe`, `crashreporter.exe`) пропускаются без изменений.

## Быстрая установка на Windows

Скопируйте два файла из папки `windows/dist/` (или из архива `hoi4-accel-v1.3.0-windows-x64.zip` в GitHub Releases):
1. `version.dll`
2. `hoi4_accel.ini`

прямо в корневую папку установленной игры рядом с `hoi4.exe` (обычно `...\Steam\steamapps\common\Hearts of Iron IV\`).

Запускайте игру как обычно. После старта рядом с `hoi4.exe` появится лог инициализации **`hoi4_accel.log`**, подтверждающий подключение всех модулей `v1.3-win64`.

> **Для мультиплеера:** выставьте `preset = pure` и одинаковые флаги `ai_*` у всех игроков в `hoi4_accel.ini`, чтобы избежать рассинхронов (OOS).

## Что оптимизировано в `hoi4.exe` (`v1.3-win64`, MSVC x64)

### Новое в `v1.3` — Полный фикс пустых клеток, автостроитель сухопутных `supply_node` и умный танковый ИИ

| Модуль | RVA / VTable в `hoi4.exe` | Что делает |
| :--- | :--- | :--- |
| **`AiTacticalPrudence v3` + Empty-Tile Fix** | `0x1573929, 0x1573933` (`CUnitOrder`) + `.data` `0x33e76b8..0x33ec038` | **Полностью исправлен затуп перед пустыми клетками**: снят порог `too_weak` на ветке нулевого гарнизона в активных батлпланах (`CanMoveIntoProvince` сохранён), снижен `MIN_PLAN_VALUE_TO_MICRO_INACTIVE` до `-1.00`, а `MAX_MICRO_ATTACKS_PER_ORDER` поднят до `10`. Плюс сбережение снаряжения и танковые кулаки **`AIFC`** |
| **`AiSmartSupply v2`** | `0x13a9fc0` (`FixSupplyBottlenecks`) + `0x11d0110` (`CAddConstructionCommand`) + `0x02b6700` (`CSession::Post`) | К ежедневной логистике, апгрейдам ЖД и моторизации добавлен **нативный автостроитель сухопутных узлов снабжения (`supply_node`)**: на горящих фронтах (`>= 3` дивизий с `< 50%` снабжения, `>= 20` заводов) ставит 1 узел в безопасной тыловой клетке с проверкой 3-шаговым BFS (макс. 1 активный узел в очереди, кулдаун 30 дней) |
| **`AiSmartArmor`** | VTable `0x27b8be0+0x20` (`GetStrategyValue`) + `0x25416a0` (`CToken::FromString`) + `9` параметров `NDefines::NAI` | Промышленно-масштабируемый приоритет `armor` / `mechanized` (от `>= 22` военных заводов с 1938+ года, с мягким снижением перекоса чистой пехоты), снижение `PRODUCTION_EQUIPMENT_SURPLUS_FACTOR` (`1.00→0.55`) и ускорение апгрейда/создания танковых шаблонов (`UPGRADES_DEFICIT_LIMIT_DAYS 60→210`, XP `35→20`) |

## Настройка и откат версий

- Откройте `hoi4_accel.ini` любым текстовым редактором: любой модуль (`ai_smart_armor`, `ai_smart_supply`, `ai_tactical_prudence`, `ai_smart_peace`, `ai_smart_airbase`, `fast_alloc` и др.) можно отключить индивидуально, убрав `;` и поставив `= 0`.
- Для полного отката на `v1.2.0`, `v1.1.0` или `v1.0.0` скачайте нужный архив из раздела **Releases** на GitHub и замените `version.dll` рядом с `hoi4.exe`.
- Для полного удаления просто удалите `version.dll` и `hoi4_accel.ini` из папки с `hoi4.exe`.
